# Portfolio

Portfolio of Mohamed Aziz Ghazouani: https://aziz-ghazouani.pages.dev

One static page, `index.html`, in English and French. There is no build step.
Cloudflare Pages (project `aziz-ghazouani`) serves this folder as it is and
redeploys on every push to `main`. The repository keeps its old
`AzizGh69.github.io` name, but GitHub Pages is switched off.

- `img/`: the hero photo
- `cv/`: the two CVs linked from the System screen

The music toggle is parked: `MUSIC_FILE = null` in `index.html` keeps it hidden.
`audio/` is gitignored until a track the site has the rights to arrives.
