# CV source

Both CVs are generated by `build.py` from one content source, as LaTeX, and
compiled with [Tectonic](https://tectonic-typesetting.github.io) (installed at
`C:\Users\aziz6\AppData\Local\Programs\tectonic\tectonic.exe`).

```powershell
cd D:\Portfolio-V2\cv\source
python build.py
Move-Item -Force Mohamed-Aziz-Ghazouani-CV-*.pdf ..
```

Edit the text in `build.py`, not in the `.tex` files: they are overwritten.
The script also checks what an ATS reads: one page, plain hyphens, no broken
characters. Keep IBM Plex Sans or Fira Sans; Source Sans and Lato export their
hyphens as special characters that ATS keyword searches can miss.
